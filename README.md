# 🤖 AI News Chatbot

An AI-powered News Chatbot that fetches real-time news using external News APIs and provides intelligent news interactions through NLP techniques.

## 🚀 Features

* 📰 Real-time news fetching
* 🤖 AI-powered chatbot interface
* 🔍 NLP-based query processing
* 🌍 Category-wise news filtering
* 📱 Responsive web application
* 🔐 User authentication
* ☁️ Cloud deployment support

## 🛠️ Tech Stack

### Frontend

* React.js
* Firebase Hosting
* Axios
* CSS

### Backend

* Node.js
* Express.js
* MongoDB
* JWT Authentication

### AI / NLP Service

* Python
* Flask
* NLP Processing

### APIs

* News API
* External AI/NLP APIs

## ⚙️ Environment Variables

### Backend (.env)

```env
PORT=5001
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
SESSION_SECRET=your_session_secret
NEWS_API_KEY=your_news_api_key
NODE_ENV=production
CLIENT_URL=your_frontend_url
PYTHON_API_URL=your_python_api_url
```

### Python Service (.env)

```env
NEWS_API_KEY=your_news_api_key
FLASK_ENV=development
FLASK_APP=app.py
CORS_ORIGINS=your_frontend_url
PORT=5000
```

### Frontend (.env)

```env
REACT_APP_API_URL=your_backend_url
REACT_APP_PYTHON_API_URL=your_python_service_url
```

## 🏃 Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Backend

```bash
cd Aibackend
npm install
npm start
```

### Frontend

```bash
cd news-chatbot-frontend
npm install
npm start
```

### Python Service

```bash
pip install -r requirements.txt
python app.py
```
